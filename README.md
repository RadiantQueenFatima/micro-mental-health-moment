# Your First Micro Mental Health Moment™

A digital, mobile-friendly copy of Dhorea Ramanula's "Micro Mental Health
Moment" conference worksheet. Static site — no backend, no data storage.

## Run locally

```
npx serve .
```

Then open the printed local URL in a browser.

## Deploy

Static site, zero config. Import this repo into Vercel ("Add New Project" →
Import Git Repository) and deploy — no build command or output directory
needed.
